# 인테리어 견적 비교 (Interior Quote Compare)

업체마다 양식이 다른 인테리어 견적서를 **표준 공정 기준**으로 정리해서 비교하는 웹 앱.

총액만 보면 싸 보이는 업체가 사실은 빠진 공정이 많은 업체인 경우가 흔하다.
이 앱은 공정별 포함/누락 상태를 추적하고, 누락 공정을 타 업체 평균가로 채운
**동일 조건 환산 총액**을 계산해서 진짜 비교가 가능하게 한다.

## 주요 기능

- **붙여넣기 등록 (무료, AI 없음)** — 견적서에서 복사한 텍스트를 붙여넣으면 키워드 사전 + 정규식으로 항목·금액을 추출하고 공정에 자동 분류. 전부 클라이언트에서 동작해 비용 0원. 결과는 검수 화면에서 확인·수정 후 확정
- **CLI AI 연동 (JSON 붙여넣기)** — Claude Code 같은 CLI AI에게 견적서 파일을 정해진 JSON 형식으로 변환시킨 뒤 붙여넣으면 같은 검수 화면으로 등록. 서버 API 키 없이 AI 파싱 품질을 활용하는 경로 (형식은 붙여넣기 탭의 안내 참고)
- **AI 파싱 (선택 기능)** — 서버에 `ANTHROPIC_API_KEY`가 설정된 경우, 견적서 PDF/사진 업로드만으로 Claude가 항목·금액을 추출하고 표준 공정에 자동 매핑. 확신 못 하는 항목은 표시해서 사용자가 검수·수정 후 확정

- **실제 견적서 기반 표준 공사 15종** — 실제 인테리어 견적서 2건(같은 단지 24/25평형)의 공사 구조에서 도출: 가설·신고/철거/확장·단열/샤시/도어·중문/목공/설비/전기·조명/타일/욕실/주방·가구/도배/도장·필름/바닥/기타. 그 아래 기본 세부항목 + 커스텀 세부항목으로 입력
- **견적서 그대로의 세부항목** — 품명·규격·단위·수량·단가·금액·비고, 단가×수량 자동계산, "미정·별도·직접구매" 옵션 항목(합계 제외) 지원
- **견적서 메타** — 평형, 이윤·공과잡비 %, 단수조정, VAT 처리, 공사기간. 총액 = 공급가×(1+이윤%)+조정+VAT — 실제 견적서 2건과 원 단위까지 일치 검증
- **평당가 비교** — 평형이 다른 견적끼리도 평당 총액으로 비교
- **공정 상태** — 세부항목이 있으면 포함, 없으면 `미포함 / 다른 공정에 묶임 / 확인 필요`로 구분해 "빠진 것"과 "다른 항목에 녹아 있는 것"을 분리
- **기준 업체 비교** — 업체 카드를 클릭해 기준 업체를 정하면, 다른 업체의 공정별 비용이 기준 대비 ▲더 비쌈/▼더 저렴으로 표시
- **공정별 평균가** — 해당 공정을 포함한 업체들의 평균 비용을 공정마다 표시
- **공정 드릴다운** — 공정을 클릭하면 그 공정만 세부항목 단위로 업체 간 비교
- **동일 조건 환산 총액** — 누락·미확인 공정을 다른 업체들의 평균가로 보정한 총액으로 공정한 비교
- **비용 구성 차트** — 업체별 공정 비용 스택 바 차트

## 기술 스택

- **Next.js 15** (App Router) + **TypeScript** — 프론트엔드 + API Route Handlers
- **Prisma + SQLite** — 별도 인프라 없는 로컬 DB (Postgres 전환 용이)
- **Tailwind CSS 4**
- **Recharts**
- **Claude API** (`@anthropic-ai/sdk`) — AI 파싱(선택 기능)에만 사용. 키가 없어도 나머지 기능은 전부 동작

## 실행

```bash
npm install
cp .env.example .env   # 견적서 업로드 기능을 쓰려면 ANTHROPIC_API_KEY 입력
npm run db:setup       # DB 스키마 생성 + 표준 공사 시드
npm run db:demo        # (선택) 실제 견적서 2건 데모 데이터
npm run dev
```

http://localhost:3000 에서 확인.

## 데이터 모델

```
Category         표준 공사 (시드 15개 + 커스텀)
SubItemTemplate  공사별 기본 세부항목 (예: 욕실 → 도기·수전·젠다이)
Vendor           업체 + 견적서 메타(평형, 이윤%, 단수조정, VAT, 공사기간)
LineItem         세부항목: 품명·규격·단위·수량·단가·금액·비고·옵션 여부
QuoteItem        업체 × 공사 상태: EXCLUDED | BUNDLED | UNKNOWN
                 (세부항목이 하나라도 있으면 포함으로 간주)
```

### 보정 총액 계산 로직 (`src/lib/calc.ts`)

- 공정 금액 = 그 공정 세부항목(LineItem) 합계
- `rawTotal` = 포함 공정 금액 합계
- `adjustedTotal` = rawTotal + Σ(미포함·미확인 공정의 타 업체 평균가, '기타' 제외)
- 다른 공정에 묶임(BUNDLED)은 이미 반영된 것으로 보고 보정하지 않음
